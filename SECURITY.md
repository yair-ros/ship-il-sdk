# Security Policy

## Supported Versions

Security fixes are best-effort for the latest release on `main`.

## Reporting a Vulnerability

Do not open a public GitHub issue for vulnerabilities that expose:

- API credentials
- customer data
- shipment labels
- order, address, or tracking data

Use GitHub's private vulnerability reporting for this repository if it is
enabled. If it is not enabled, contact the repository owner privately before
publishing details.

Include:

- affected version
- steps to reproduce
- impact
- whether real credentials or customer data are involved

## Scope

This repository is an independent/community SDK for the SHIP Israel API.
Reports about the upstream SHIP platform itself may also need to be disclosed to
SHIP directly through the relevant vendor support channel.
